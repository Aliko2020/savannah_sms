# Edusavannah - School Management System

**Edusavannah** is a comprehensive, cloud-based school management platform designed to streamline administrative operations, student workflows, and academic tracking. 

The platform consists of a public-facing marketing website and a dedicated web application portal for administrators, teachers, and students.

---

## 🔗 Live URLs

- **Marketing Website:** [https://edusavannah.com/](https://edusavannah.com/)
- **Application Portal:** [https://app.edusavannah.com/login](https://app.edusavannah.com/login)

---

## 🛠️ Tech Stack & Architecture

### Infrastructure & Operations
* **Database:** PostgreSQL (Containerized)
* **Backend:** REST API Services running on Docker containers
* **CI/CD Pipeline:** GitHub Actions for automated linting, testing, and cloud deployments
* **Hosting / Cloud Server:** Cloud Server with Docker Compose runtime
